# ProjektJavaEE

A Java EE-based web application project configured with Maven, designed as a foundation for enterprise-level development using Jakarta EE technologies.

## 🧰 Technologies & Frameworks

- **Java 11**
- **Maven**
- **Jakarta EE 10+**, including:
  - Jakarta Servlet API
  - Jakarta Persistence (JPA)
  - Jakarta EJB
  - CDI (Contexts and Dependency Injection)
  - Jakarta Mail
- **Hibernate ORM**
- **H2 Database (in-memory)**
- **JUnit 5 & Mockito** for unit testing

## 📦 Packaging

- **WAR** file (`.war`) generated using the `maven-war-plugin`
- Suitable for deployment on a Jakarta EE-compatible application server (e.g., Payara, WildFly, TomEE)
